# DeepKOALA v0.4-beta

This beta release adds optional KO definitions to prediction CSVs, streaming
inference for large FASTA inputs, and unified CPU, CUDA and Apple Silicon MPS
device selection. It includes the February 2025 model resources.

## Changes since v0.3-beta

- Add `--description` to append KO definitions in standard and multi-domain
  CSV output, including detailed and top-k results. Definitions are loaded from
  the selected model release's `ko_description.csv`.
- Stream standard inference input and output, preserve input order, and publish
  completed CSVs atomically.
- Add CUDA memory presets, adaptive batching and configurable OOM handling.
- Support `--device auto`, `cpu`, `cuda` and `mps` consistently across inference
  modes.
- Fix HMMER invocation for paths containing spaces or shell metacharacters, and
  close temporary files before the external tool opens them.
- Add cross-platform compatibility tests, deterministic random-sequence tests
  and focused regression coverage for description output and HMMER cleanup.

## Download and run

Download **Source code (zip)** or **Source code (tar.gz)** from this release and
extract it. These archives contain the code, the `202502` model weights and KO
configuration, `ko_description.csv`, and its resource README. From the extracted
directory, install dependencies in a Python 3.11 virtual environment and run:

```bash
python -m pip install -r requirements.txt
python -m deepkoala.cli -i proteins.fasta -o results.csv --description
```

See the repository README for GPU installation and other inference options.
For `--multi`, install HMMER and download the matching KOfam profiles separately;
pass the extracted directory with `--profiles_dir`. HMMER profiles are not
included in this release. No wheel or PyPI package is published by this release.

The Git tag is `v0.4-beta`; the Python project version is `0.4b1`. The model
resource version remains `202502`. Newer model resources are distributed through
[GenomeNet](https://www.genome.jp/ftp/db/deepkoala/).

## Validation and scope

Release publication requires the CPU compatibility matrix to pass: Linux,
Windows and macOS with Python 3.11 / PyTorch 2.4.1, plus Linux with Python 3.12 /
the current PyTorch version below 3. Tests use synthetic resources. Local
pre-release validation passed 299 tests, including three real HMMER 3.4 cases,
and 32 inference combinations using random protein sequences and the bundled
models. Six CLI runs checked both models from an isolated source layout,
including default `latest` resource selection and agreement with the Python API
at the same batch size.
These checks do not establish biological accuracy, calibrate thresholds, or
replace validation on real CUDA and MPS devices. This remains a pre-release.
